# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's "Report a vulnerability" option on the repository's Security tab, if it is available. Otherwise, open an issue that asks for a private contact channel and leave out the technical details.

Include the affected version, the impact, and the steps needed to reproduce the problem.

## Scope

This project is a local library and CLI. It has no network listener, authentication, or data store. Assignment hashes are not a security control and must not be used for authorization.
